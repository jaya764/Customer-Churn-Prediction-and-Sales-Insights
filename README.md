
# 📊 Customer Churn Prediction & Sales Insights

## 📌 Project Overview
This project focuses on analyzing customer purchase behavior and predicting customer churn using SQL, Python Machine Learning, and Power BI. The project helps identify churn risks, understand customer purchasing patterns, and generate business insights to support data-driven decision-making.

The project was completed through three major stages:
- 🛠️ Data cleaning and transformation using SQL
- 🤖 Customer churn prediction using Machine Learning models
- 📊 Interactive dashboard creation using Power BI


## 🧰 Tools & Technologies Used
- Python
- SQL
- Power BI
- Pandas
- Scikit-learn
- Matplotlib


## 📂 Dataset Information
The dataset contains customer transaction records including:
- Customer details
- Product category
- Purchase amount
- Payment method
- Order information
- Churn status

### 📁 Datasets Used
- Transaction-level purchase dataset
- Customer summary dataset created for Machine Learning modeling


## 🗄️ SQL Data Preparation
SQL was used for:
- ✅ Checking NULL values
- ✅ Removing duplicate records
- ✅ Churn distribution analysis
- ✅ Creating customer summary tables
- ✅ Data aggregation and transformation


## 🤖 Machine Learning Models

### 📈 Logistic Regression
Used to analyze the relationship between purchase behavior and churn probability.

### 🌳 Decision Tree
Used to identify feature-based decision patterns and improve interpretability.

### 🌲 Random Forest
Used to improve prediction accuracy and reduce overfitting by combining multiple decision trees.

**🏆 Random Forest achieved the best performance among all models.**


## 📊 Power BI Dashboard
An interactive dashboard was developed to visualize:
- 💰 Total Revenue
- 📦 Total Orders
- 👥 Total Customers
- 🛒 Total Quantity Sold
- 📈 Revenue Trends
- 🧾 Revenue by Product Category
- 💳 Payment Method Analysis
- 🚨 Top High-Value Churned Customers


## 🔍 Key Insights
- Identified customer churn patterns using Machine Learning
- Analyzed revenue trends and customer purchasing behavior
- Detected high-value customers who churned
- Generated insights to support customer retention strategies
